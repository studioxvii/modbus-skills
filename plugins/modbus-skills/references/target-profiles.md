# Target Profiles

## Node-RED

Generate importable JSON with environment-based endpoint settings. Read compiled blocks and derive logical points from one immutable block response.

## Modpoll (BETA)

`gavinying-cli` generates its documented CSV records for the gavinying/modpoll CLI.

`proconx-cli` generates bounded proconX FieldTalk `modpoll` commands for the
Windows verification lab and other proconX installs.

`witte-desktop` generates readable plans and documented automation. Let the installed application create native files.

`witte-v12-xml` generates XML read documents for the named format, distinct from
desktop automation. Verify native open/read behavior in the exact installed version.

Native verification is product-, profile-, version- and artifact-specific. Generated
files retain `not-run` status until their own native check; another profile's receipt
does not establish compatibility.

## ModScan (BETA)

Generate readable setup and poll-plan files. Do not synthesize undocumented binary projects.

CSV files are operator-entry instructions, not native imports. The generated Point
Address column is scoped to the tested ModScan64 UI; other native behavior remains
unverified until the relevant checks run.

See `addressing-and-native-verification.md` for the address base each target uses
