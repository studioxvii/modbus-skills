# Capture Modbus Sample

Create a bounded read-only probe for collecting raw Modbus words through Node-RED, Modpoll, or ModScan. Use for sample acquisition before byte-order or datatype review. Use a target generator when the request is only to render a named output from an existing canonical map and read plan.
