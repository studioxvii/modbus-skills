Modbus Skills

Review a register map

Produce a reviewed Modbus map without silent engineering guesses.

Steps

  1. parse-modbus-map: source-bundle/v1 → candidate-map/v1
  2. normalize-modbus-map: candidate-map/v1 → modbus-map/v1
  3. lint-modbus-map: modbus-map/v1 → modbus-map-lint/v1
  4. review-modbus-evidence: modbus-map/v1, modbus-map-lint/v1 → modbus-map-evidence-review/v1
  5. human-gate: modbus-map/v1, modbus-map-evidence-review/v1 → modbus-review-decisions/v1
    Resolve every blocking hold and state each value or exclusion with a reason and evidence reference.
  6. apply-modbus-review-decisions: modbus-map/v1, modbus-review-decisions/v1 → modbus-map/v1

Stop conditions

  • unresolved route or address convention
  • unresolved register area
  • unresolved unit identifier
  • unreviewed rejected rows
  • unconfirmed multi-register byte order
