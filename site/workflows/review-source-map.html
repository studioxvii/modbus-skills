Review a raw source map end to end

Produce a reviewed draft and compact exception queue when source-map review itself is the requested outcome.

Steps

  1. review-map: source-bundle/v1 → modbus-map-evidence-review/v1
  2. human-gate: modbus-map/v1, modbus-map-evidence-review/v1 → modbus-review-decisions/v1
    Skip when the review status is ready. Otherwise resolve every independent exception group in one batch.
  3. apply-review: modbus-map/v1, modbus-review-decisions/v1 → modbus-map/v1

Stop conditions

  • user actually wants organized user-map outputs
  • unresolved route or address convention
  • unresolved register area
  • unconfirmed multi-register byte order
