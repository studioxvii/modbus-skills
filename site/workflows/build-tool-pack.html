Workflow · 3 steps

Build a multi-target tool pack

Generate any selected combination of Node-RED, Modpoll (BETA), and ModScan (BETA) from one validated map and one read plan.

You start with

  • a reviewed Modbus map

You receive

the selected read-only tool files.

How it works

  1. Check Map

    Run deterministic register-map checks

    Starts with a reviewed Modbus map. Produces deterministic map validation findings.

  2. Plan Reads

    Compile bounded Modbus read blocks

    Starts with a reviewed Modbus map. Produces a bounded Modbus read plan.

  3. Build Tool Pack

    Build several Modbus tool outputs

    Starts with a reviewed Modbus map, a bounded Modbus read plan, a reviewed map and selected target tools. Produces the selected read-only tool files.

When it stops

  • No selected target.
  • Map validation error.
  • Required final decoding field unresolved.
  • Write request detected.
