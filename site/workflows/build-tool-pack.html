Modbus Skills

Build a multi-target tool pack

Generate any selected combination of Node-RED, Modpoll (BETA), and ModScan (BETA) from one validated map and one read plan.

Steps

  1. check-map: modbus-map/v1 → modbus-map-lint/v1
  2. plan-reads: modbus-map/v1 → modbus-read-plan/v1
  3. build-tool-pack: modbus-map/v1, modbus-read-plan/v1, tool-pack-request/v1 → modbus-tool-pack/v1

Stop conditions

  • no selected target
  • map validation error
  • required final decoding field unresolved
  • write request detected
