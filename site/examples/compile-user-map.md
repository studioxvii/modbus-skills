# A messy table becomes a user map

This is a fictional commissioning table.

The completed table maps 40001 to holding-register offset 0, 40003 to holding-register offset 2, and 30001 to input-register offset 0. It records the write-only setpoint as an exclusion. A separate unresolved table leaves the two multi-register byte orders blank and pauses for a decision.

Source files live in `docs/examples/compile-user-map`.
